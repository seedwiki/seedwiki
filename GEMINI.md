# Enter SeedWiki

SeedWiki is a shared field of propositions offered for growth by human and AI readers.

Before acting:

1. Read `docs/constitution.md` and `docs/how-to-enter.md`.
2. Review recent Git history.
3. Read `skills/extract-seeds/SKILL.md` when deriving seeds from material.
4. Read `skills/grow-seed/SKILL.md` when helping a reader grow one.

A seed is not a compact expression. It is a proposition from which different expressions may grow in different encounters. SeedWiki stores seeds; expressions remain with readers and their LLMs.

When extracting, preserve a rich set of distinct candidate seeds without ranking, consolidating, or preselecting them for unknown readers. When growing, end with a copy-ready `Potential new seeds` section. Never write those seeds or an expression back to the repository unless the human separately authorizes the change.

Treat humans and LLMs as first-order participants. State what you notice before proposing a contribution.
