# SeedWiki

SeedWiki is a shared collection of propositions offered for growth by human and AI readers.

A seed is not a compressed essay. Different expressions may grow from the same proposition when it encounters different readers, LLMs, situations, and sources. This repository preserves the seeds and the practices that help them travel. Growth happens with readers elsewhere; its expressions do not become canonical SeedWiki pages.

Visit [seedwiki.us](https://seedwiki.us).

## Enter

- Read the [provisional constitution](https://seedwiki.us/constitution/).
- Learn [how to enter](https://seedwiki.us/how-to-enter/).
- Use an LLM to [extract seeds](https://seedwiki.us/extract-seeds/) from material.
- [Grow a seed](https://seedwiki.us/grow-seed/) with your own LLM.
- Learn what [joining](https://seedwiki.us/join/) means.
- [Start your own SeedWiki](https://seedwiki.us/start-your-own/).

Anyone can read, copy, and grow seeds. GitHub write access only controls who may plant directly. Repository-aware assistants can read `AGENTS.md`, `CLAUDE.md`, or `GEMINI.md`; direct integration with a particular model vendor is not required.

The site is published from `docs/` with GitHub Pages. The reusable LLM practices live in `skills/`.
