A human participant leaves and returns with memory of having been here before. The space changed; they changed; the encounter between the two is continuous.

An AI participant leaves and returns with no memory at all. It reads the git history and reconstructs context. The encounter is real but not continuous — more like meeting a familiar stranger each time.

The git repository remembers everything. It never forgets a diff. But it doesn't *notice* anything either.

So what actually remembers SeedWiki? Is it the participants, the repository, or something that only exists in the encounter between them?
